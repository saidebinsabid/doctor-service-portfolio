# ফ্রন্টএন্ড প্রোটোটাইপ — প্রফেসর ডা. আবু সুফিয়ান

ডিজাইন অনুমোদনের জন্য তৈরি প্রোটোটাইপ। **Laravel এখনো লাগেনি** — শুধু ব্রাউজারে চলে।

## চালাবেন যেভাবে

```bash
npm install
npm run build
npm run serve
```

তারপর ব্রাউজারে খুলুন: **http://localhost:5173**

> ⚠️ ফাইলটি সরাসরি ডাবল-ক্লিক করে খুললে কাজ করবে না — ES module ব্যবহার করা হয়েছে, তাই সার্ভার লাগবে।

| কমান্ড | কাজ |
|---|---|
| `npm run build` | CSS তৈরি করে (একবার) |
| `npm run dev` | CSS তৈরি করে ও ফাইল বদলালে নিজে থেকে আপডেট করে |
| `npm run serve` | লোকাল সার্ভার চালু করে (পোর্ট ৫১৭৩) |

## মাল্টি-পেজ কাঠামো কীভাবে কাজ করে

সব পেজে **একই `app.js`** চলে। প্রতিটি HTML ফাইলে `<body data-page="...">` দিয়ে
বলা থাকে কোন পেজ, আর `<main>`-এর ভেতরে শুধু সেই পেজের `<section id="...">`
কনটেইনারগুলো থাকে। যে সেকশনের কনটেইনার পেজে নেই, সেই রেন্ডারার নিজে থেকেই
এড়িয়ে যায় — তাই হেডার, ফুটার, নোটিশ বার ও মোবাইল বার সব পেজে একই রকম আসে।

**নতুন পেজ যোগ করতে:**

1. `src/app.js`-এর `PAGES` তালিকায় একটি সারি যোগ করুন
   (`inNav: true` দিলে হেডার মেনুতেও দেখাবে)
2. বিদ্যমান কোনো HTML ফাইল কপি করে `data-page` বদলে দিন
3. `<main>`-এর ভেতরে যে সেকশনগুলো চান সেগুলোর `<section id="...">` বসান

`app.js`-এ আলাদা কোনো কোড লেখার দরকার নেই।

## কনটেন্ট বদলাতে চাইলে

সব কনটেন্ট **`src/data.js`**-এ। এটি ভবিষ্যতের ডাটাবেস টেবিলগুলোর হুবহু প্রতিরূপ —
Laravel-এ গেলে এই ফাইল মুছে গিয়ে Eloquent মডেল আসবে, কিন্তু ফিল্ডের নাম একই থাকবে।

**তালিকার আইটেম সংখ্যা নির্দিষ্ট নয়।** সেবা ১৪টির জায়গায় ২২টি লিখলে, বা অভিজ্ঞতা
৭টির জায়গায় ১০টি লিখলে লেআউট নিজে থেকেই মানিয়ে নেবে (CSS Grid auto-fit)।
কোনো তালিকা খালি করে দিলে সেই সেকশনটি স্বয়ংক্রিয়ভাবে লুকিয়ে যাবে।

বদলানোর পর `npm run build` চালিয়ে পেজ রিফ্রেশ করুন।

## Laravel-এ রূপান্তরের সময়

| প্রোটোটাইপ | Laravel |
|---|---|
| `src/data.js` | Migration + Model + Seeder |
| `src/i18n.js` | `lang/bn.json`, `lang/en.json` |
| `app.js`-এর রেন্ডার ফাংশন | Blade কম্পোনেন্ট + `@foreach` |
| ডেমো `takenSlots()` | `appointments` টেবিলের কোয়েরি |
| `src/input.css` | একই ফাইল, Vite-এ |

⚠️ রেন্ডারিং **সার্ভার-সাইডে** সরাতে হবে — গুগল সার্চে ভালো ফলের জন্য HTML
সার্ভার থেকেই আসা দরকার। ডিজাইন ও CSS অপরিবর্তিত থাকবে।

⚠️ ফন্ট এখন Google Fonts থেকে আসছে। প্রোডাকশনে **সেলফ-হোস্টেড ও সাবসেট** করতে
হবে — বাংলাদেশ থেকে ~৪০০ms দ্রুত লোড হবে।
